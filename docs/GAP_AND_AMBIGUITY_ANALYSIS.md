# Gap & Ambiguity Analysis (Stage 4F)

## Gaps = package completeness + analysis coverage (never bidder scoring)
Deterministic: missing files, unsupported types, failed extraction (with
error), empty OCR/text, referenced-but-absent forms (Exhibit/FORM/Annex
regex vs inventory), empty package. Every gap carries evidence. No company
capability source exists in scope, so "company failed requirement" is
unrepresentable by construction.

## Ambiguity = typed, evidence-grounded, review-oriented
Types: missing-value (TBD/applicability markers), unclear-date-anchor
(relative duration in SCHEDULE/COMMERCIAL without anchor), undefined-term
(UNKNOWN abstention), unclear-applicability (obligation wording + null
mandatory flag), plus conflicting-wording / incomplete-reference /
cross-document-inconsistency slots for future backends. Each item:
evidence (doc#page), clarification_needed=true, human_review_required=true.
No severity, ever.
