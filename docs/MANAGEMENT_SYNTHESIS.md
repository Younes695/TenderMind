# Management Synthesis (Stage 4F MVP)

Deterministic template over validated findings (AI synthesis NOT_CONFIGURED):
key obligations (mandatory=true, capped), requirements by category, deadlines,
commercial facts (each slot falls back to "not available in validated
material"), gaps, ambiguities, conflicts, risk observations, document status,
plus an uncertainty note (null/UNKNOWN = unknown, not negative).

MUST NOT (tested): invent facts/severity/probabilities, produce BID/NO-BID,
hide uncertainty. Empty sections return explicit unavailable states, never
placeholders. Every claim traces to validated artifact IDs.
